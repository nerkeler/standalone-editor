基线：`dc5da9d`；开始日期：2026-10-01。实施由 GPT-6 Luna（max）完成，主代理独立审查、运行回归并检查真实截图。定位保持个人、本机或可信局域网 Markdown 工作台，测试只使用隔离工作区。

“各项 9 分以上”是改进目标，不能代替验收证据。评分必须说明支持范围、实测平台和剩余限制；没有测过的真实设备、Windows/NAS/掉电场景不计为已验证。

| 维度 | 本轮完成标准 |
|---|---|
| 功能闭环 | 目录选择、文件打开、编辑、三秒保存、冲突、恢复、图片/表格全部核心回归通过；合法语法与保护提示含义清楚 |
| 数据可靠性 | 存储拒绝/配额异常不阻断服务端保存；写失败不改原文件且不遗留本次临时文件，不删除外来文件；既有安全测试不退化 |
| Markdown 与可移植性 | 富文本支持子集往返测试、源码保护/确认修复、相对图片路径与显示属性重开持久化通过 |
| 桌面视觉 | 任务列表正常对齐、工具语义清楚、正文层级稳定；明暗主题及长内容截图复审 |
| 操作效率 | 目录、文件树、菜单、大纲、表格选择器可键盘操作，焦点可见且返回合理；不会形成64次Tab链 |
| 移动与无障碍 | 390px/768px不溢出、常用触控目标与图片手柄命中区舒适、200%缩放与键盘路径检查；真实手机限制如实记录 |
| 性能 | 建立隔离数据上的启动/扫描/搜索测量；移除无必要扫描，控制首次加载与合理拆包，无未经证明的复杂索引 |
| 质量保障 | 单元、后端、构建、浏览器、可选截图全套连续通过；测试视口/状态隔离；新增生产产物验收 |
| 可维护性 | 提取有实际职责的codec/UI/存储与后端app边界；现有行为不变，模块接口可测试 |
| 发布与维护 | 运行依赖告警处理有记录、构建产物启动及健康/退出验收、升级回退与备份说明同步；不自动改变用户许可或部署远程 |

顺序：先修已复现缺陷，再补关键验收，再进行克制精修与结构优化，最后复评。每轮复查优先处理观察到的失败，验证通过后不为刷分反复扩大改动。

本轮不自动推送 GitHub、不更新远端服务、不接触真实笔记；最终向用户报告实际成果与仍未达标的维度。
